# Layouts and desktop presets

Open **Layouts** to choose a built-in desktop layout or manage a custom preset. Built-ins include GNOME, Ubuntu Unity, Windows 10/11/XP, Arc Desktop and macOS. Review the change preview before applying; use the toast’s Undo to restore the previous layout.

## Common tasks

- Choose **Arc Desktop** for a translucent bottom taskbar and Arc-style launcher.
- Save your current setup with a unique name in **Custom Desktop Presets**.
- Select a saved preset, then use **Preview…** before applying it.
- Rename or delete a selected preset with the corresponding controls.
- Export/import presets to share Orbit configuration; imported presets are stored before you choose whether to apply them.

## Saved state and scope

**Layouts → Custom Desktop Presets** saves Orbit settings and the window-button layout.
Save, rename, delete, export or import a preset, then use Preview to review every change
before applying. Apply supports Undo. Built-in presets reset only the settings owned by
the built-in layout family; pins, tray rules and other unrelated customization remain.
Preset files are validated before storing or applying, including embedded command shortcuts.
They do not install GTK/icon themes or copy wallpapers, application data or packages.
