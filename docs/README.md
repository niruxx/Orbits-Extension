# Orbit Shell documentation

Open **Extensions → Orbit Shell → Settings** to configure Orbit, or run:

```sh
gnome-extensions prefs orbit-dock@niruxx.github.io
```

Commands in these guides are run from the repository root unless stated otherwise.
