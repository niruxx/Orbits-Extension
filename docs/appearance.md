# Appearance and effects

Use **Dock**, **Top Bar**, **Launcher** and **Effects** for appearance. Orbit changes Shell surfaces; it does not install GTK/icon/cursor themes, wallpapers, system fonts, login-screen themes or boot splashes.

## Common tasks

- Change a panel’s color and opacity on **Top Bar**, including Arc’s bottom taskbar.
- Change launcher colors, fonts, borders, corners and spacing on **Launcher**.
- Change the applications button’s icon, label and color on **Launcher**.
- Save launcher appearance under **Launcher → Saved Themes and Launcher Backups**.
- Enable independent blur/brightness controls per surface under **Effects**.
- Turn on **Reduced effects** to disable glass and icon hover animations.
- Turn off a surface’s glass for plain transparency; its opacity then blends directly with what is behind it.

## Rendering and controls

**Frosted glass**: the launcher blurs the live wallpaper and application windows behind it.
Its backdrop is bounded to the menu and clipped with the same corner radius, leaving the
rounded corners transparent. Dock and top bar use wallpaper blur by default; their live-window blur is optional under Effects. Surface
opacity controls the tint over the blur; turn off Frosted glass for plain transparency.

**Effects** offers independent blur strength and brightness for dock, panel and launcher.
Each surface can blur the live window scene or use wallpaper only. The **Reduced effects**
switch disables all glass and icon hover effects. Global blur settings remain the fallback
until a surface's independent controls are enabled. Launcher changes apply on next opening.
